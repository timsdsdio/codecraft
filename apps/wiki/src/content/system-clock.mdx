The **System Clock** provides the current time through <Iface id="core.Clock@1" />. It has no inputs, which makes it one of the simplest blocks there is.

## Usage

[[memory-todo-repo|Memory Repo]] takes a clock to timestamp new todos. Anything that needs the time should take a clock rather than reading it directly, so a test world can plug in a fake clock instead.

<SceneFigure name="wiring" float="none" height={240} caption="The clock and ID generator feeding Memory Repo." />

## Interface

```ts
interface Clock {
  now(): number
}
```
