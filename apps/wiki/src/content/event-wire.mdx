An **event wire** is a function prop seen from the other end. A parent passes `onToggle` up to a child; when the child calls it, a signal comes back down. Wires are thin red cables that run beside the [[Pipe|pipes]]. They stay dark until they're used.

## When an event fires

1. You click something on the [[Screen]]. A spark appears where you clicked.
2. A red pulse runs down from the clicked component's casing along the wire, floor by floor, to the casing that created the handler.
3. If the handler changes state, the matching [[State Tank]] sloshes, and the [[Render]] wave starts climbing.

## Where the wire ends

The [[Probe]] follows a function prop down by identity. `TodoItem` got `onToggle` from `TodoList`, which got it from `App`, which made it. So the wire runs all the way to `App`, even though `TodoList` only passed it along.
