The first version of CodeCraft is built around one small app: a todo list with a scrolling list, an add form and filters. It's ordinary React with nothing visualizer-specific in it. It was chosen because it has each thing the factory needs to show:

- state at the root (`todos`, `filter`) and local state (`AddTodo`'s `title`);
- props going down two levels;
- callbacks coming back up two levels (`onToggle`, `onRemove`);
- a keyed list (`todos.map`);
- a scroll area (the list).
