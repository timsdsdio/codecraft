You carry four **tools** in a hotbar. Every tool does one thing to whatever the crosshair is on.

| Slot | Tool | Use on | Result |
|---|---|---|---|
| <Key>1</Key> | <ToolIcon tool="probe" size={20} /> [[Probe]] | block, socket, cable | inspect it |
| | | screen | open the live app |
| <Key>2</Key> | <ToolIcon tool="wire" size={20} /> [[Wire Coil]] | socket, then a matching socket | run a cable |
| <Key>3</Key> | <ToolIcon tool="cutter" size={20} /> [[Wire Cutters]] | cable | cut it |
| | | socket | cut every cable on it |
| <Key>4</Key> | <ToolIcon tool="wrench" size={20} /> [[Wrench]] | block | pick it up |
| | | floor, while carrying | set it down |

Right click, <Key>Q</Key>, or the touch Cancel button backs out of a half-made cable or a carried block. See [[Controls]] for every input.

## Why tools

- **Dragging doesn't work in first person.** The mouse is turning your head. A crosshair makes the target simply "what you're looking at".
- **Choosing and doing are separate.** The wrench can't cut by accident; the coil can't move a block by accident.
- **Phones.** One thumb walks, one looks, and a tap on the thing you want uses the current tool there. No hover, no precise drag.
- **Reach.** Targets must be within 6.5 m. You walk up to a socket to wire it, so where things are in the room matters.

## The tooltip

Aim at anything and a tooltip at the top of the screen names it, in the style of Jade/WAILA:

- a **block**: its name, zone and id
- a **socket**: its shape swatch, interface, input or output, how many cables it takes and holds
- a **cable**: `from → to` and its interface

The crosshair turns into the aimed socket's shape in its colour. It turns red when the coil is aimed at a socket that can't take the cable.
