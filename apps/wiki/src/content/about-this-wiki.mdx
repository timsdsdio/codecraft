This wiki is the design document for CodeCraft. It's written as a game wiki so that every idea gets described the way a player would meet it: what a machine looks like, what it's connected to, and what it tells you.

## Workflow

1. Write or change a page.
2. Discuss it, and change it again. Many rounds are expected.
3. Once a page is agreed, set its status to `settled`.
4. Build it. Anything the build does differently from the page goes in `DEVIATIONS.md`, and the page is updated to match.

## Writing pages

Pages are MDX files in `apps/wiki/src/content/`. The file name is the page's address: `logic-casing.mdx` is `/wiki/logic-casing`. Each file starts with frontmatter:

```yaml
---
title: Logic Casing
category: Machines        # Concepts, Machines, Gameplay, Reference, Engineering, Meta
summary: One line for search and category lists.
status: draft             # draft | open | settled
aliases: [Casing]         # other names that link here
infobox:
  scene: casing           # a 3D scene from the Scene Gallery
  caption: Plain text under the 3D view.
  rows: { Inputs: "props (bottom)" }
---
```

Link to another page with `[[Page name]]` or `[[Page name|link text]]`. A link to a page that doesn't exist shows up red. Inside a table, write the pipe as `\|`.

## 3D views

Drop a scene anywhere with `<SceneFigure name="fold" caption="…" />`. It takes `float` (`right`, `left`, `wide`, `none`), `width` and `height`. The [[Scene Gallery]] lists every scene. `/special/scene/<name>` shows one full size, which is handy while working on it.

Scenes live in `apps/wiki/src/embeds/scenes.tsx`. They're built from `packages/visuals`, the same components the game will use. Most of them run the [[Todo App]] snapshot (`src/data/todoApp.ts`) through the real layout function ([[World Layout]]). A scene only starts rendering when it's near the screen. Every 3D view has a ⛶ button that opens it fullscreen to **explore**: walk around it in first person (<Key>W</Key><Key>A</Key><Key>S</Key><Key>D</Key> and mouse; on a phone, a joystick and drag-to-look), use <Key>Space</Key> / <Key>Shift</Key> (▲ / ▼ on touch) to move between floors, or switch to orbit. The **TRON / BRASS** button in the top bar switches the look of every scene (it's remembered in your browser).

## Other helpers

- `<Kind k="array" />`: a value kind with its colour.
- `<KindTable />`, `<ComponentTable />`, `<TodoSource />`: generated from the reference app.
- `<Question>…</Question>`: a highlighted unresolved design question.
- `<Key>E</Key>`: a key cap.
