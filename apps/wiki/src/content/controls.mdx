CodeCraft is played in **first person** by default: you walk around inside the program. The [[Map View]] is one key away.

## First person

| Action | Desktop | Touch |
|---|---|---|
| Move | <Key>W</Key><Key>A</Key><Key>S</Key><Key>D</Key> / arrows | left-half joystick |
| Look | mouse (drag to look if pointer lock isn't available) | right-half look pad |
| Jump | <Key>Space</Key> | Jump button |
| Sprint | <Key>Shift</Key>, or double-tap <Key>W</Key> | push the joystick past 90 % |
| Use tool | left click, <Key>E</Key> | tap the target |
| Cancel | right click, <Key>Q</Key> | Cancel button |
| Pick tool | <Key>1</Key>–<Key>4</Key>, wheel | tap the hotbar |
| Map view | <Key>M</Key> / <Key>Tab</Key> | toggle in the HUD |
| Respawn | <Key>R</Key> | from the pause card |

The joystick and look pad track separate fingers, so you can strafe and turn at once.

## Movement

You're 1.8 m tall and a [[Block]] is 1.4 m, so a block is something you can *just* jump onto, as in Minecraft. There's no auto-step: walking into a block stops you. You can stand and walk on top of blocks, and from there see over the [[Network Wall]].
