The **Wrench** moves [[Block|blocks]].

1. Use it on a block to pick it up. The block floats in front of you, translucent. While carried it isn't solid.
2. Use it on the floor to set it down. It snaps to the half-metre grid inside its own [[Zone]].

Cables stay plugged in while a block moves, and stretch to follow it. Moving a block never changes the running app.

The [[Monitor]] is bolted down; the wrench refuses it.
