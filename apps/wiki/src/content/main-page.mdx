**CodeCraft** is a tech mod where the machines are programs. Every part of an app is a [[Block]]. Every TypeScript interface is a [[Socket]] with its own shape and colour. You build working software by running [[Cable|cables]] between blocks, and the app runs live on a [[Monitor]].

This wiki is where the design gets worked out *before* it gets built. Pages describe how things should work. When a design is agreed it gets implemented, and the wiki stays as the player-facing reference.

## Reading this wiki

Each page carries a design status:

- **Prototype**: how the Socketworld prototype already works. A starting point, open to change.
- **Draft**: a proposal that hasn't been agreed.
- **Open question**: options for something undecided.
- **Settled**: agreed, and ready to build.

Red links like [[Crafting]] point to pages nobody has written yet. The [Wanted pages](/special/wanted-pages) list collects them, so it doubles as the design backlog. See [[About this wiki]] for how pages and 3D views are written.
