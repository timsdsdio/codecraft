The **Probe** is a scanner pen with a glowing tip. Use it on something to open the inspector for it.

## Uses

| Aimed at | Result |
|---|---|
| a [[Block]] | the inspector: description, sockets, what each is plugged into |
| a [[Socket]] | the same, scrolled to that socket, with its full interface type |
| a [[Cable]] | both ends and the interface it carries |
| the [[Monitor]] screen | the live app, full size, so you can use it |

<Question>
