The **Mock Link** sits in the portal of the [[Network Wall]] and carries the TodoApi [[Cable#Network cables|network cable]] across it. It takes <Iface id="todo.TodoApi@1:handler" female /> on the server side and provides <Iface id="todo.TodoApi@1:remote" /> on the client side.

## Behaviour

For each call it:

1. copies the request (so the client and server never share an object),
2. waits 60–150 ms,
3. calls the server,
4. copies the response back.

The delay is long enough to see loading states and to watch pulses cross the wall. The copying means anything that couldn't survive a real network fails now, not later.

<SceneFigure name="link" float="none" height={250} caption="A call crosses the wall and its response comes back." />

## Replacing it

An [[HTTP Link]] would look the same from both sides, so swapping it in changes nothing else in the world.
